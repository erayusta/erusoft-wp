Customer-specific and customer-group prices for WooCommerce.

== Description ==

Set special prices or percentage discounts for individual customers or customer groups, per product, category or the whole catalogue. A configurable label tells customers they see a special price. Nothing changes until you create a rule.

It can run next to Role-Based Prices and Price Lists for WooCommerce; precedence is customer rule, then price list, then role price.

Requires WooCommerce 9.0 or newer; compatible with HPOS. The admin interface is in Turkish.

Diğer Erusoft eklentileri: https://wordpress.erusoft.com

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it. WooCommerce is required.
3. Configure it in the WooCommerce admin menu. Nothing changes on the storefront until you do.

== Frequently Asked Questions ==

= What is removed on uninstall? =
Only the plugin's own options and data. Data attached to orders is kept.
