Creates a .webp copy of every uploaded JPEG/PNG and size on your own server, with bulk regeneration and picture-tag serving.

== Description ==

Creates a .webp copy of every uploaded JPEG/PNG and each generated size with GD or Imagick, regenerates existing media in batches with a progress bar, serves via <picture> (or swapped URLs) and shows an .htaccess snippet that it never writes itself. No external service.

The admin interface is in Turkish. Diğer Erusoft eklentileri: https://wordpress.erusoft.com


== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it.
3. Configure it under its Settings screen.
