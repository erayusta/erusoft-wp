Generates a print-ready product catalogue from WooCommerce categories; save as PDF from the browser.

== Description ==

Generates a print-ready product catalogue (cover page, products grouped by category, image/name/SKU/price options) from selected WooCommerce categories. Save it as PDF from the browser's print dialog (Turkish glyphs render with the browser's fonts). No PDF library is bundled; the eru_ppc_render_pdf filter lets you plug in a server-side engine. Default: admin-only; no public download until enabled.

Requires WooCommerce 9.0 or newer; compatible with HPOS. The admin interface is in Turkish. Diğer Erusoft eklentileri: https://wordpress.erusoft.com


== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it (WooCommerce must be active).
3. Configure it as described in the Turkish README; until configured the plugin leaves the store unchanged (except where noted in the description).
