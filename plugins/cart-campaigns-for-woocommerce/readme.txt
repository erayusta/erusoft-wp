Tiered cart-threshold discounts with a progress message.

== Description ==

Tiered cart-threshold campaigns with a progress message in the cart and mini-cart ("add X more and get Y off"). Only the highest tier reached applies. With no tiers the plugin does nothing.

Requires WooCommerce 9.0 or newer; compatible with HPOS. The admin interface is in Turkish.

Diğer Erusoft eklentileri: https://wordpress.erusoft.com

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it. WooCommerce is required.
3. Configure it in the WooCommerce admin menu. Nothing changes on the storefront until you do.

== Frequently Asked Questions ==

= What is removed on uninstall? =
Only the plugin's own options. Data attached to products or orders is kept.

= Which tier applies? =
Only the highest tier whose threshold the cart subtotal has reached.
