Named price lists assigned to roles or users.

== Description ==

Create named price lists with a catalogue-wide percentage, per-category percentages and fixed prices, then assign them to user roles or individual users. The cart and checkout use the list price. Nothing changes until you publish a list.

It can run next to Role-Based Prices and B2B Customer Pricing for WooCommerce; precedence is customer rule, then price list, then role price.

Requires WooCommerce 9.0 or newer; compatible with HPOS. The admin interface is in Turkish.

Diğer Erusoft eklentileri: https://wordpress.erusoft.com

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it. WooCommerce is required.
3. Configure it in the WooCommerce admin menu. Nothing changes on the storefront until you do.

== Frequently Asked Questions ==

= What is removed on uninstall? =
Only the plugin's own options and data. Data attached to orders is kept.
