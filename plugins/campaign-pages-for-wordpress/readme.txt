A campaign post type with start and end dates that hides ended campaigns automatically.

== Description ==

Adds a campaign post type with start/end dates, banner, call-to-action and an archive page whose slug you choose. Ended campaigns drop out of the archive and the [eru_campaigns] shortcode on their own. Works with classic and block themes; WooCommerce is optional (link a campaign to a product or category).

The admin interface is in Turkish. Diğer Erusoft eklentileri: https://wordpress.erusoft.com

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it.
3. Add campaigns under Campaigns > Add New; adjust the archive slug under Campaigns > Ayarlar.
