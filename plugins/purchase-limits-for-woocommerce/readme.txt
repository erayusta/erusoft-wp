Sets min/max quantities per product, category and order, and per-customer limits over a period.

== Description ==

Minimum and maximum quantities per product, per category and per order, plus a per-customer limit within a rolling period (by user or billing e-mail). Messages are configurable. No limits are active until you set them.

Requires WooCommerce 9.0 or newer; compatible with HPOS. The admin interface is in Turkish.

Diğer Erusoft eklentileri: https://wordpress.erusoft.com

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it. WooCommerce is required.
3. Configure it in the WooCommerce admin menu. Nothing changes on the storefront until you do.

== Frequently Asked Questions ==

= What is removed on uninstall? =
Only the plugin's own options (and scheduled events). Data attached to products or orders is kept.
