Reorder products in brand and category archives by drag and drop.

== Description ==

Drag and drop the order of products inside a brand, category or any product taxonomy archive. The order is stored per term and applied only to that archive's main query, only under the shop's default sort. Nothing changes until you save an order.

Requires WooCommerce 9.0 or newer; compatible with HPOS. The admin interface is in Turkish. Diğer Erusoft eklentileri: https://wordpress.erusoft.com

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it (WooCommerce must be active).
3. Configure it as described in the Turkish README; until configured the plugin leaves the store unchanged (except where noted in the description).
