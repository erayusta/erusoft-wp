== Description ==

With visitor consent, records checkout e-mail/phone/first name and cart contents when someone leaves checkout, and gives call-centre staff a follow-up list with statuses (to call / called / unreachable / ordered) and notes. Marks recovered orders automatically and purges old rows (default 30 days). Disabled until you enable it; includes WordPress privacy exporter/eraser.

Diğer Erusoft eklentileri: https://wordpress.erusoft.com

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it. WooCommerce is required.
3. Configure it under the WooCommerce menu.

== Frequently Asked Questions ==

= Is anything changed on the storefront right after activation? =
No. The plugin does nothing visible until you configure it.

= What is removed on uninstall? =
Its own options and its lead table. Order meta is kept.
