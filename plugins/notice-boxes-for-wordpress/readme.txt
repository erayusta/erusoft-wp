Info, warning, success and error boxes in three style presets as a shortcode and a Gutenberg block with dark-mode support.

== Description ==

Info/warning/success/error boxes in three style presets (soft, solid, outline) as the [eru_notice] shortcode and a server-rendered Gutenberg block (eru/notice-box, no build step). Dark-mode aware.

The admin interface is in Turkish. Diğer Erusoft eklentileri: https://wordpress.erusoft.com


== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it.
3. Configure it under its Settings screen.

== Frequently Asked Questions ==

= Does it send data anywhere by default? =
No. It does not use any external service.
