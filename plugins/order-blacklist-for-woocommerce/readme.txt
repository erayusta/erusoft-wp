== Description ==

Blocks checkout for blocklisted e-mails (or whole domains), phone numbers, IP addresses or address fragments. Lists are empty by default. A log keeps the last 100 blocked attempts (matched rule only, no visitor data).

Diğer Erusoft eklentileri: https://wordpress.erusoft.com

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it. WooCommerce is required.
3. Configure it under the WooCommerce menu.

== Frequently Asked Questions ==

= Is anything changed on the storefront right after activation? =
No. The plugin does nothing visible until you configure it.

= What is removed on uninstall? =
Its own options. Order meta is kept.
