Different product and variation prices per user role.

== Description ==

Set a different price per user role on products and variations. The roles that get custom prices are picked in the settings (none by default), so nothing changes until you configure it.

Requires WooCommerce 9.0 or newer; compatible with HPOS. The admin interface is in Turkish.

Diğer Erusoft eklentileri: https://wordpress.erusoft.com

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it. WooCommerce is required.
3. Configure it in the WooCommerce admin menu. Nothing changes on the storefront until you do.
