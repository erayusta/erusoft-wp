Store pickup as a proper WooCommerce shipping method (zones compatible).

== Description ==

Store pickup as a proper WooCommerce shipping method (zones compatible). Define pickup locations (name, address, hours); the customer picks one at checkout, it is validated server-side, saved on the order and shown in the admin order, e-mails, thank-you page and My Account. Optional "Ready for pickup" order status. No locations = method not offered.

Diğer Erusoft eklentileri: https://wordpress.erusoft.com

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it. WooCommerce is required.
3. Configure it under the WooCommerce menu.

== Frequently Asked Questions ==

= Is anything changed on the storefront right after activation? =
No. The plugin does nothing visible until you configure it.

= What is removed on uninstall? =
Its own options. Order meta is kept.
