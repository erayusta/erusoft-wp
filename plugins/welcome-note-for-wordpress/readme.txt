== Description ==

A dismissible welcome note for chosen roles in the admin area and an optional front-end announcement bar. Dismissal is remembered per user (user meta + nonce'd AJAX); changing the text shows it again.

The admin interface is in Turkish. Diğer Erusoft eklentileri: https://wordpress.erusoft.com


== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it.
3. Configure it under its Settings screen.

== Frequently Asked Questions ==

= Does it send data anywhere by default? =
No. It does not use any external service.
