# Güvenlik politikası / Security policy

## Açık bildirimi

Erusoft WP eklentilerinden veya temalarından birinde güvenlik açığı bulduysanız **herkese açık GitHub issue açmayın**. Ayrıntıları konu satırına "Güvenlik" yazarak **hello@erusoft.com** adresine gönderin:

- etkilenen ürün ve sürüm,
- açığın türü ve etkisi,
- yeniden üretme adımları (varsa kavram kanıtı).

Bildirimleri en kısa sürede yanıtlamaya çalışırız. Düzeltme yayımlanana kadar ayrıntıları gizli tutarız ve isterseniz sürüm notlarında adınızı anarız. Lütfen gerçek müşteri verisi, şifre veya API anahtarı göndermeyin.

## Desteklenen sürümler

Güvenlik düzeltmeleri her ürünün en güncel sürümüne yapılır ve https://wordpress.erusoft.com üzerinden yeni ZIP olarak yayımlanır.

## English

Please do not open public issues for security vulnerabilities. E-mail **hello@erusoft.com** with "Security" in the subject, the affected product and version, the impact and steps to reproduce. We aim to respond quickly, keep details private until a fix ships, and fix the latest release of each product. Never include real customer data, passwords or API keys.
